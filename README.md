# Informatique 1 — Dr. Farida Larit

Student learning hub for L1 Sciences de la Matière, Université Frères Mentouri Constantine 1.

## Publish from your PC

1. Extract this ZIP into a folder on your PC.
2. Open https://github.com/laritfarida-star/informatique-1
3. Choose Add file → Upload files.
4. Drag the CONTENTS of the extracted folder into the upload area: index.html, app.js, README.md and the materials folder. Do not upload the ZIP or an enclosing folder.
5. Commit the changes to main. Replacing the initial README.md is expected.
6. Open repository Settings → Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Choose main and / (root), then Save.
9. Wait for GitHub to finish deployment. The intended address is:
   https://laritfarida-star.github.io/informatique-1/
   This address is not active until deployment succeeds.

If folder dragging does not work, use Chrome or Edge on your PC and drag the materials folder from Windows File Explorer.

## Add teaching materials

Open the materials folder in GitHub, choose Add file → Upload files, upload your documents and commit changes.
To show a new document on the website, also add its entry to the items array at the top of app.js. Existing entries are examples of the required format. Send the filename and desired section to ChatGPT if you want help preparing the entry.
Uploading a document alone does not add a resource card automatically.

Use short filenames without spaces, such as TP1-S2-Student.pdf. Keep the exact spelling and capitalization in the page link.
This repository and its files are public. Upload student-facing materials; keep teacher-only corrections separately unless you intend to release them.
Use hosted video links for large video recordings.

## Files

- index.html: page layout and design
- app.js: resource catalogue, filters and interactions
- materials/: downloadable teaching files

The package includes Course 1 Session 2 slides, Online TP 1 student worksheet and supplementary exercises. The video section is awaiting recordings.

## Preview locally

Double-click index.html to open the page in your browser. Keep app.js and materials beside it.

This is a static website. It has no upload dashboard, student submission system or Python execution service. The density widget performs its calculation in JavaScript; the Python example can be downloaded for IDLE.
